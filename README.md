# KuroRacing 🏎️

Web-based 3D racing game with realistic physics and synthwave aesthetic.

Night falls. Neon rises. You race.

## Tech

- **Engine:** Babylon.js 6.x
- **Language:** TypeScript
- **Build:** Vite
- **Physics:** Custom Pacejka-inspired tire model + raycast suspension

## Dev

```bash
npm install
npm run dev
```
